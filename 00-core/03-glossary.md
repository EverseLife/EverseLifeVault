# Словарь терминов

> **Статус:** живой

Единственный источник правды по терминам. Если термин не здесь — его не существует.

---

## Мир

| Термин                 | Значение                                                                                                                                                                    |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **everse.life**        | Название игры и игровой вселенной. Пишется **латиницей, строчными, с точкой: `everse.life`** во всех языках; регистр не меняется и в начале предложения. Никогда не переводится и не транслитерируется (D-079, написание — D-250) |
| **Терра**              | Землеподобная планета, точка спавна людей                                                                                                                                   |
| **Акватика**           | Океаническая планета нимф. **Вне альфы** (D-104): отложена без назначенного срока.                                                                                                                                    |
| **Пироксис**           | Вулканическая планета, единственный источник пироксита. Спавн запрещён                                                                                                      |
| **Аврора**             | Ледяная планета с руинами людей Предтеч. Спавн запрещён                                                                                                                     |
| **Люди Предтеч**       | **Настоящие люди.** Исчезнувшая высокотехнологичная цивилизация: создала технологию биопринтера и первый биопринтер. Её руины — на Авроре, её город — под столицей Терры     |
| **Человек-киборг**     | Играбельная линия. Тело печатается **только биопринтером**, мышление обеспечивает встроенный процессор. Не потомок Предтеч, а их изделие                                     |
| **Биопринтер Предтеч** | Оригинальный артефакт на Терре. Работает на бесконечной атомной энергии; Находится в столице планеты Терра.                                                                 |
| **Биопринтер**         | Копия Принтера, строится игроками. Обязательная постройка города-государства. Печатает тела за энергию и металл                                                             |
| **Древо**              | Аналог биопринтера у нимф. **Вне альфы** (D-104): линия нимф отложена, термин закреплён и переиспользованию не подлежит                                           |
| **Облако**             | Хранилище личностей в Сети. Состояние мозга отгружается непрерывно и лежит на всех биопринтерах и Древах сразу; личность неуничтожима, пока жив хотя бы один узел           |
| **Тело**               | Расходуемая оболочка с процессором. Теряется при гибели вместе со всем содержимым. Может быть переработано.                                                                 |
| **Печать**             | Изготовление нового тела и загрузка в него личности. Стоит энергии и металла                                                                                                |
| **Локация**            | Минимальный узел карты и лист графа: одна постройка — мастерская, рынок, шахта, дом. Место, где находится персонаж (D-089)                                                    |
| **Узел**               | Вершина графа на любом масштабе; локация — узел нижнего уровня. В узле ровно одна постройка                                                                                  |
| **Кольцо**             | Расстояние в шагах от биопринтера в центре города. Чем дальше кольцо, тем больше в нём мест и тем дешевле участок                                                            |
| **Ядро города**        | Локация с биопринтером. Центр радиального графа города и самое людное место: там появляется каждый умерший                                                                   |
| **Регион**             | Группа узлов с общими свойствами (климат, ресурсы, принадлежность)                                                                                                          |
| **Космический корабль** | Группа узлов графа, связанных между собой, с одним узлом-коннектором наружу. Не предмет и не транспорт: стыковка и отстыковка — появление и исчезновение одного ребра (D-201) |
| **Узел борта**         | Узел, принадлежащий кораблю: рубка, трюм, каюта, машинное. Обычный узел карты со своей площадью, чатом и рабочими станциями; планета у него — та, в чьём порту корабль стоит: она меняется с каждой стыковкой          |
| **Коннектор**          | Единственный узел борта, смыкающийся с космодромом. Он же основание корабля, заложенное первым. Узкое место для досмотра и захвата — и оно ровно одно                        |
| **Космодром**          | Постройка, к которой стыкуется корабль. Требует чистого неба — свойства самого узла, а не здания                                                                             |
| **Стоянка**            | Круг вокруг планеты радиуса `orbit.park_radius`, на котором висит пришвартованный к орбитальному узлу корабль: аналитический, а не интегрируемый (D-289)                     |
| **Автопилот**          | Единственный способ вести корабль: на каждом тике заново прокладывает переход оттуда, где корабль сейчас, и жжёт топливо по ходу. Ручного управления нет (D-289)               |
| **Дрейф**              | Состояние корабля, у которого кончилось топливо: двигатели молчат, его несёт инерция под тяготением пяти тел. В копии — «дрейф»; «коста» (D-289) — то же слово движка, игроку не показывается |
| **Удержание**          | Два корпуса, вставшие рядом (ближе `orbit.dock_radius`, медленнее `orbit.dock_speed`), летят как один: подошедший держится за опорный и читает его состояние (D-289, волна 3)                            |
| **Стыковка борт к борту** | Ребро коннектор ↔ коннектор при удержании и согласии обоих командиров; по нему ходят с канистрами. Только в космосе (D-289, волна 3)                                                          |
| **Встреча (рандеву)**  | Приказ с целью-кораблём: рулевой приходит к косте дрейфующего корпуса и гасит скорость до удержания (D-289, волна 3)                                                          |
| **Командир**           | Тот, кто отдаёт приказ корпусу: владелец у рубки этого корпуса или у наземной консоли (D-242). Стыковка борт к борту — с согласия обоих командиров                             |
| **Инерция**            | Линия, по которой корабль пойдёт, если двигатели встанут сейчас, и её вердикт: устойчивый круг, столкновение с телом в такой-то час, уход из системы. Считает сервер, рубка рисует (D-289) |
| **Астроцентрическая орбита** | Круг вокруг звезды через место корабля, прямой, как у планет: приказ `ship.orbit` гасит разницу скоростей полной тягой, дальше корабль висит на круге как дрейфующий, и вердикт инерции считается как у любого (D-289, 2026-09-04) |
| **Тяговооружённость**  | Отношение суммарной тяги двигателей к массе корабля с оборудованием, грузом и экипажем. Задаёт время рейса; ниже `ship.min_thrust_ratio` корабль не отстыковывается (D-202)   |
| **Извержение**         | Событие Пироксиса: перекраивает рёбра и переносит жилы, построенного не трогает. Ритм планеты, а не катастрофа (D-197)                                                       |
| **Сигнал**             | Обязательное бесплатное предупреждение всем, кто в зоне извержения. Окно на отступление, исполнение П6                                                                       |
| **Прогноз**            | Предсказание извержения по району. Опережает сигнал, сбывается не всегда, требует труда — и потому продаётся                                                                 |
| **Сеть**               | Инфраструктура Предтеч, связывающая всех людей и все биопринтеры. Резервирует личности, несёт связь и удалённые действия. Для игрока — внутриигровой мессенджер               |
| **Группа**             | Кружок собеседников внутри локации. Слышен только участникам, но иногда просачивается наружу                                                                                 |
| **Запись разговора**   | Единственный способ сохранить живое общение. Городские постройки пишут всегда, дома игроков — никогда; игрок может писать носимым предметом, открыто или скрытно. Доказательство в суде |
| **Маркетплейс**        | Терминал торговли. Товар загружается и забирается физически, ордера управляются удалённо                                                                                     |
| **Смотритель**         | Должность в городе: право менять описание, баннер и фон локаций                                                                                                             |
| **Энергетик**          | Должность в городе: содержит электростанцию, закупает топливо, распоряжается пулом                                                                                          |
| **Палитра планеты**    | Набор цветов планеты. Задаёт и иллюстрации локаций, и тему интерфейса: Терра — тёмно-синяя. Меняется при перелёте                                  |
| **Баннер локации**     | Широкое детализированное изображение сверху. Парадный портрет места                                                                                                         |
| **Фон локации**        | Приглушённое малодетализированное изображение под содержимым основного окна. Держит атмосферу и молчит                                                                        |

## Материя и труд

| Термин | Значение |
|---|---|
| **Доказательство труда / PoW** | Механика, при которой базовое сырьё добывается только через реальное внимание живого игрока. **Не** криптографический хеш |
| **Сырьё** | Материал, полученный напрямую из мира: руда, дерево, волокно, зерно, вода |
| **Жила** | Конкретный истощаемый источник сырья в узле |
| **Пироксит** | Руда Пироксиса. Обязательный компонент высоких крафтов |
| **Передел** | Один шаг обработки: руда → слиток → деталь → изделие |
| **Рецепт** | Знание, хранящееся в процессоре игрока. Без него крафт невозможен |
| **Носитель рецепта** | Физический предмет с записанной копией рецепта. Продаётся, теряется при гибели |
| **Библиотека** | Хранилище рецептов у людей. Полнейшая — в столице Терры, но построить может любой город. Точка входа в ремесло |
| **Архив** | То же самое у нимф. Термин закреплён и переиспользованию не подлежит, хотя линия отложена (D-104) |
| **Мудрец** | Должность у людей: ведёт Библиотеку города. Правит порядок, но не может отказать во вкладе или изъять положенное |
| **Хранитель** | То же у нимф: ведёт Архив поселения. Вне альфы вместе с линией |
| **Изобретение** | Попытка получить неизвестный рецепт экспериментом. Тратит материалы |
| **Потолок качества** | Наименьшее из качества станции и качества инструмента. Рецепт на качество не влияет |
| **Участок** | Земля во владении: узел с площадью в м² и титулом. Покупается, арендуется, продаётся меной |
| **Делянка** | Размеченная часть участка: одна культура, один срок, одно состояние, один обход. Плодородие и история культур принадлежат ей, а не разметке (D-118) |
| **Агротехника** | Текст «как ухаживать» за культурой: полоса влаги, подкормка по фазам, чего не прощает, выносливость. Собирается из данных культуры, читается в Библиотеке, запоминается во вкладку «Знания», пересказывается; не вещь и не гейт интерфейса (D-057, D-296) |
| **Уход** | Отдельные присутственные действия на делянке — полив до целевой влаги, подкормка в фазу; общей кнопки нет (D-296). Смотреть состояние можно по Сети откуда угодно, ухаживать — только на месте |
| **Влага** | Вода в земле делянки, 0–100: уходит долей от текущей — по жажде культуры и погоде, у реки вдвое медленнее, — поднимается поливом. Единственная шкала делянки, показанная кривой (D-296) |
| **Здоровье делянки** | Накопленный стресс культуры, 0–100: падает пропорционально разрыву между влагой и полосой, от ожога удобрением; ноль — гибель. Скрыто целиком, игрок видит слово (D-296) |
| **Фаза роста** | Всходы, лист, цветение, налив, спелость — всё, что игрок знает о сроке: рост зависит от ухода, и суток до спелости не показывают никому (D-296) |
| **Сорняк** | Засорённость делянки, 0–100: растёт с посева, быстрее на жирной земле, пьёт воду и тянет рост; снимается прополкой. Виден с порога, всем (D-297) |
| **Теснота** | Непрореженный посев: штраф урожая по боязни загущения культуры (`density_risk`); прореживание один раз и рано снимает его за свою долю (D-297) |
| **Напасть** | Беда делянки, пришедшая за ошибку ухода: грибок от перелива, клещ от суши, насекомые от сорняка, бактериоз от промаха подкормки. Скрытое давление копится в сутки и разряжается напастью; поражение режет урожай и тянет здоровье (D-299) |
| **Знак** | Что видно на делянке глазом: пятна, паутина, погрызы, гниль. Знак у каждой напасти свой и виден всем; чем его гасят — знает тот, кто прочёл агротехнику (D-057, D-299) |
| **Обработка** | Действие с средством одного из четырёх классов: гасит давление своей напасти и держит защиту, а по больной делянке останавливает расход, но не лечит — поражённое потеряно (D-299) |
| **Уставка** | Число, которое держит полевой автомат: целевая влага, удобрение по фазе. Автомат держит число, но растения не видит (D-120, D-296) |
| **Полевой автомат** | Машина, исполняющая программу по делянкам вместо человека. Слепа к симптомам и не умеет отбирать на семена (D-120) |
| **Программа** | Безусловный цикл команд полевого автомата: посеять, полить, подкормить, убрать, пар. Условий в ней нет — севооборот задаётся порядком |
| **Блюдо** | Продукт готовки. Портится быстрее сырья, из которого сделано, поэтому продаётся там же, где готовится (D-119) |
| **Роль** | Место в составе блюда — основа, наполнитель, жир, приправа. В роль годится любой подходящий продукт; сочетание задаёт вид блюда |
| **Сочетание** | Набор продуктов по ролям. Удачное сохраняется именем автора и торгуется как знание — наравне с пропорцией смеси |
| **Утварь** | Инструмент готовки: горшок, котёл. Изнашивается, теряется при смерти, задаёт потолок качества блюда |
| **Горячее** | Еда, которая восполняет меньше сразу, но снижает расход выносливости на несколько часов. Требует качества выше порога, поэтому машинной не бывает (D-121) |
| **Регулируемый товар** | Товар, на который город назначил цену законом. К нему же применяются норма отпуска и граница (D-122) |
| **Норма отпуска** | Сколько регулируемого товара один человек может взять по цене потолка за сутки. Без неё потолок цены скупают оптом |
| **Беспошлинная норма** | Сколько товара человек проносит через границу города бесплатно за сутки. Отделяет бытовой провоз от промысла (D-123) |
| **Справочная цена** | Медиана сделок городского стакана за `trade.reference_price_window`. По ней считается пошлина. Сделок не было — пошлину не с чего считать |
| **Торговая сводка** | Суточный отчёт города: ввоз, вывоз, пошлины, производство и баланс по каждому товару. Прибор, по которому власть правит ставки (D-124) |
| **Сорт** | Стабильная культура: семена дают то же самое всегда. Выводится многими поколениями отбора |
| **Гибрид** | Потомство скрещивания: превосходит родителей, но семена нестабильны |
| **Отбор** | Выбор растений на семена при сборе урожая. Основа стабилизации сорта |
| **Рабочая станция** | Стационарное оборудование внутри здания. **Задаёт, чем это здание является** (D-106): верстак делает его мастерской, стеллажи — складом. До D-200 называлась станком |
| **Здание** | Универсальная постройка на участке. Различаются прочность, площадь и этажность; расход материалов считается формулой, а не рецептом. Имя даёт владелец |
| **Покрытие** | Свойство ребра карты: бездорожье, дорога или мощёный тракт. По бездорожью транспорт не идёт вовсе (D-107) |
| **Тип рецепта** | Постройка, рабочая станция, инструмент, снаряжение, транспорт, материал, расходник, монета. Определяет поведение предмета в движке (D-090) |
| **Смесь** | Рецепт, состав которого задан пропорцией, а не штуками: сплавы, стекло, растворы, химия. Только у них качество зависит от точности пропорции (D-092) |
| **Стройка** | Статус **здания** между началом работ и их завершением: видно, чего не хватает и кто уже внёс (D-131). Рабочей станцией не бывает: станции собираются руками либо на другой станции, как всякая вещь (D-216) |
| **Скопление** | Сжатый узел карты: три и более однотипных мелких построек показываются одним и разворачиваются по клику (D-097) |
| **Выход** | Узел-переход из города на слой планеты. Не место, а дверь наружу |
| **Основа узла корабля** | Предмет верфи. Отдав его на космодроме, закладывают основание корабля; отдав его на борту — расширяют корабль ещё одним узлом (D-202) |
| **Артель** | Несколько игроков на одной бедной жиле: выход каждого растёт с числом соседей (D-099). Делёж — договор, движок в него не входит |
| **Ранение** | Приходит от среды: обвал, газ, жар, отказ снаряжения. Повышает расход выносливости, пока не залечено; лечится временем или врачом (D-096) |
| **Плата устройства** | Фиксированный объём память-затратных вычислений на каждую сессию добычи. Мощность даёт доступ, но не преимущество; дорого обходится масштаб, а не автоматизация (D-110, D-112) |
| **Буровая установка** | Рабочая станция непрерывной добычи. Требует топлива, обслуживания и вывоза руды; даёт много средней руды вместо мало хорошей (D-115) |
| **Заключение** | Санкционный примитив: принудительное удержание в узле на срок по приговору |
| **Выносливость** | Личный запас киборга. Темп расхода выбирает игрок; восполняется мгновенно едой и медленно гибернацией. Потолка на сутки нет (D-091). Не путать с **энергией** — та городской ресурс |
| **Гибернация** | Остановка тела киборга: медленно восстанавливает выносливость, идёт офлайн |
| **Энергия** | Ресурс: производится городской электростанцией, тратится рабочими станциями и биопринтерами. Внутри города — общий пул, к которому всё подключено само; вне города — только аккумуляторы |
| **Электростанция** | Постройка города, обязательная как биопринтер. Частных станций внутри города нет; частный бизнес — поставка топлива |
| **Пул города** | Общий запас энергии города. Отдельных подключений и линий электропередачи нет: инфраструктура заложена в основание города |
| **Тариф** | Цена, по которой город отпускает энергию из пула любому потребителю на своей территории. Код-закон, один на город; ноль означает бесплатную энергию |
| **Износ** | Постепенная потеря пригодности предмета. Главный сток экономики |

## Экономика

| Термин | Значение |
|---|---|
| **Источник (faucet)** | Механика, вводящая ценность в мир. В everse.life по сути один — PoW-добыча |
| **Сток (sink)** | Механика, выводящая ценность из мира: износ, порча, расход, гибель, налог-сжигание |
| **Локальный рынок** | Книга заявок конкретного поселения. Глобального рынка нет |
| **Заявка** | Приказ купить/продать по цене. Bid — покупка, Ask — продажа |
| **Спред** | Разница между лучшей заявкой на покупку и на продажу. Показатель ликвидности |
| **Арбитраж** | Заработок на разнице цен между узлами. Основа профессии перевозчика |
| **Монета** | Золотая или серебряная монета, чеканится игроками. Предмет с весом. Резерв, дальняя дорога и теневой оборот |
| **Монетный двор** | Постройка для чеканки монеты из металла |
| **Проба** | Содержание металла в монете. Может быть занижена эмитентом — порча монеты |
| **Терракоин (ТК)** | Единая электронная валюта людей и единственные электронные деньги мира. Существует только как чей-то долг (D-086) |
| **Банковский хаб** | Центральный узел денежной системы в столице Терры. Не может обанкротиться |
| **Терминал** | Банк в городе: постройка, дающая доступ к счёту. Деньгами не владеет. Вне Терры не строится |
| **Резерв системы** | Уже существующие ТК в распоряжении банка. Кредит выдаётся из него, и только при нехватке недостающее печатается |
| **Оборотная масса** | ТК на счетах игроков и городов, без резерва. Именно она влияет на цены |
| **Ключевая ставка** | Цена нового долга и главный рычаг управления инфляцией. Публичная формула; позже — решение Совета городов в коридоре (D-087) |
| **Совет городов** | Орган городов Терры, которому переходит ключевая ставка. Один город — один голос |
| **Мена** | Атомарный обмен из рук в руки: обе стороны кладут в окно вещи, деньги или титулы, оба подтверждают. Бесплатно, но требует встречи (D-116) |
| **Заказ** | Договор с замороженной оплатой: сдал проверяемый результат к сроку — деньги ушли сами (D-116) |
| **Титул** | Право на участок, здание или долю. Передаётся как предмет — меной или заказом |
| **Двор** | Часть участка, не занятая застройкой. Содержания не требует; в нём стоят делянки, рабочие станции под открытым небом и транспорт (D-125). Пустое — это двор минус делянки: по нему ходит собирательство (D-246) |
| **Этаж** | Этаж выше первого — отдельная локация с лестницей вниз: свой пол и свои места под оборудование, площадью в пятно всего, что до него достаёт. Первый этаж — сам участок; дом при этом одна постройка, а закрытый этаж не удаляется, а теряет лестницу (D-247) |
| **Смета** | Расход материалов на здание. Считается от площади застройки, этажности и прочности, а не берётся из рецепта |
| **Подряд** | Заказ на стройку или ремонт: проект на узле плюс эскроу. Что не вошло в проверяемые условия — разбирает суд (D-131) |
| **Трудоёмкость** | Сколько часов труда заключено в единице предмета. Из неё выводятся количества входов во всех рецептах (D-133) |
| **Счётчик** | Учёт расхода энергии зданием: быт с метра плюс работа станций. Не заплатил — здание отключено от пула (D-135) |
| **Свойства места** | Температура, осадки, вода, плодородие и ветер узла. Разыгрываются при появлении узла; хорошего во всём не выпадает (D-126) |
| **Эскроу** | Удержание оплаты до исполнения сделки. Деньги держит банк за комиссию; товарный эскроу и сложные условия — работа игроков-посредников |

## Общество

| Термин | Значение |
|---|---|
| **Город-государство** | Игровое объединение с территорией, казной, законами и аппаратом принуждения |
| **Устав** | Конституция города: форма правления, порядок изменения законов |
| **Кодекс** | Свод действующих законов города |
| **Код-закон** | Правило, исполняемое движком автоматически (налог, пропуск, комендантский час) |
| **Закон-переключатель** | Вопрос с конечным набором вариантов; доступные варианты зависят от ранее принятых законов |
| **Слово-закон** | Правило, записанное текстом; исполняется через жалобу, суд и санкции |
| **Столица Терры** | Первый город мира. Владеет Принтером Предтеч, полнейшей Библиотекой и банковским хабом |
| **Санкционный примитив** | Действие, которое движок умеет применить к игроку по решению власти: штраф, конфискация, запрет входа, мут, метка, заключение, **присуждение** |
| **Присуждение** | Санкция, передающая спорное имущество или сумму истцу. Без неё суд наказывает, но не восстанавливает (D-117) |
| **Юрисдикция договора** | Город, в котором договор зарегистрирован и который его судит. Выбирается сторонами при заключении |
| **Гражданство** | Формальная принадлежность игрока городу. Даёт права и обязанности, включая право на печать тела |
| **Метка «вне закона»** | Статус, лишающий защиты города; насилие против носителя законно |
| **Магистрат** | Обобщённое название носителя исполнительной власти (как бы его ни назвали игроки) |
| **Репутация** | Публичная история исполненных и нарушенных обязательств |

## Технические

| Термин | Значение |
|---|---|
| **Тик** | Дискретный шаг мировой симуляции |
| **Длительное действие** | Действие, продолжающееся, пока игрок офлайн |
| **Присутственное действие** | Действие, требующее живого игрока в момент выполнения |
| **Окно реакции** | Гарантированный срок, в течение которого игрок может ответить на угрозу до необратимых последствий |

## Терминологические запреты

Не используем в документации, чтобы не тащить чужие ожидания:

- «квест» → задача/контракт (между игроками)
- «моб», «монстр» → опасность/среда
- «гильдия» → город-государство / компания
- «уровень», «опыт», «навык», «прокачка» → знание, репутация, имущество
- «аукцион» → локальный рынок
- «фарм» → добыча / производство
