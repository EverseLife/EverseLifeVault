# Словарь терминов

> **Статус:** живой документ

Единственный источник правды по терминам. Если термин не здесь — его не существует.

---

## Мир

| Термин                 | Значение                                                                                                                                                                    |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **OctoVerse**           | Название игры и игровой вселенной. Пишется **латиницей с заглавной V** во всех языках и никогда не переводится и не транслитерируется (D-079)                                |
| **Терра**              | Землеподобная планета, точка спавна людей                                                                                                                                   |
| **Акватика**           | Океаническая планета, точка спавна нимф.                                                                                                                                    |
| **Пироксис**           | Вулканическая планета, единственный источник пироксита. Спавн запрещён                                                                                                      |
| **Аврора**             | Ледяная планета с руинами людей Предтеч. Спавн запрещён                                                                                                                     |
| **Люди Предтеч**       | **Настоящие люди.** Исчезнувшая высокотехнологичная цивилизация: создала технологию биопринтера и первый биопринтер. Её руины — на Авроре, её город — под столицей Терры     |
| **Человек-киборг**     | Играбельная линия. Тело печатается **только биопринтером**, мышление обеспечивает встроенный процессор. Не потомок Предтеч, а их изделие                                     |
| **Биопринтер Предтеч** | Оригинальный артефакт на Терре. Работает на бесконечной атомной энергии; Находится в столице планеты Терра.                                                                 |
| **Биопринтер**         | Копия Принтера, строится игроками. Обязательная постройка города-государства. Печатает тела за энергию и металл                                                             |
| **Древо**              | Аналог биопринтера у нимф: живой организм, выращенный поселением. Тела нимф прорастают из него. Узел Сети наравне с биопринтерами                                           |
| **Облако**             | Хранилище личностей в Сети. Состояние мозга отгружается непрерывно и лежит на всех биопринтерах и Древах сразу; личность неуничтожима, пока жив хотя бы один узел           |
| **Тело**               | Расходуемая оболочка с процессором. Теряется при гибели вместе со всем содержимым. Может быть переработано.                                                                 |
| **Печать**             | Изготовление нового тела и загрузка в него личности. Стоит энергии и металла                                                                                                |
| **Локация**            | Минимальный узел карты и лист графа: мастерская, рынок, шахта, площадь. Место, где находится персонаж                                                                        |
| **Узел**               | Вершина графа на любом масштабе; локация — узел нижнего уровня                                                                                                               |
| **Регион**             | Группа узлов с общими свойствами (климат, ресурсы, принадлежность)                                                                                                          |
| **Сеть**               | Инфраструктура Предтеч, связывающая всех людей и все биопринтеры. Резервирует личности, несёт связь и удалённые действия. Для игрока — внутриигровой мессенджер               |
| **Группа**             | Кружок собеседников внутри локации. Слышен только участникам, но иногда просачивается наружу                                                                                 |
| **Запись разговора**   | Единственный способ сохранить живое общение. Городские постройки пишут всегда, дома игроков — никогда; игрок может писать носимым предметом, открыто или скрытно. Доказательство в суде |
| **Маркетплейс**        | Терминал торговли. Товар загружается и забирается физически, ордера управляются удалённо                                                                                     |
| **Смотритель**         | Должность в городе: право менять описание, баннер и фон локаций                                                                                                             |
| **Энергетик**          | Должность в городе: содержит электростанцию, закупает топливо, распоряжается пулом                                                                                          |
| **Палитра планеты**    | Набор цветов планеты. Задаёт и иллюстрации локаций, и тему интерфейса: Терра — тёмно-синяя, Акватика — тёмно-зелёная. Меняется при перелёте                                  |
| **Баннер локации**     | Широкое детализированное изображение сверху. Парадный портрет места                                                                                                         |
| **Фон локации**        | Приглушённое малодетализированное изображение под содержимым основного окна. Держит атмосферу и молчит                                                                        |

## Материя и труд

| Термин | Значение |
|---|---|
| **Доказательство труда / PoW** | Механика, при которой базовое сырьё добывается только через реальное внимание живого игрока. **Не** криптографический хеш |
| **Сырьё** | Материал, полученный напрямую из мира: руда, дерево, волокно, зерно, вода |
| **Жила** | Конкретный истощаемый источник сырья в узле |
| **Пироксит** | Руда Пироксиса. Обязательный компонент высоких крафтов |
| **Передел** | Один шаг обработки: руда → слиток → деталь → изделие |
| **Рецепт** | Знание, хранящееся в процессоре игрока. Без него крафт невозможен |
| **Носитель рецепта** | Физический предмет с записанной копией рецепта. Продаётся, теряется при гибели |
| **Библиотека** | Хранилище рецептов у людей. Полнейшая — в столице Терры, но построить может любой город. Точка входа в ремесло |
| **Архив** | То же самое у нимф. Разные имена одного института; путать нельзя |
| **Мудрец** | Должность у людей: ведёт Библиотеку города. Правит порядок, но не может отказать во вкладе или изъять положенное |
| **Хранитель** | То же у нимф: ведёт Архив поселения |
| **Изобретение** | Попытка получить неизвестный рецепт экспериментом. Тратит материалы |
| **Потолок качества** | Наименьшее из качества станка и качества инструмента. Рецепт на качество не влияет |
| **Агротехника** | Знание о том, что нужно конкретному сорту. Хранится в процессоре, торгуется отдельно от семян |
| **Сорт** | Стабильная культура: семена дают то же самое всегда. Выводится многими поколениями отбора |
| **Гибрид** | Потомство скрещивания: превосходит родителей, но семена нестабильны |
| **Отбор** | Выбор растений на семена при сборе урожая. Основа стабилизации сорта |
| **Станок** | Стационарное оборудование в узле. Ручной или автоматический |
| **Энергия** | Ресурс: производится городской электростанцией, тратится станками и биопринтерами. Внутри города — общий пул, к которому всё подключено само; вне города — только аккумуляторы |
| **Электростанция** | Постройка города, обязательная как биопринтер. Частных станций внутри города нет; частный бизнес — поставка топлива |
| **Пул города** | Общий запас энергии города. Отдельных подключений и линий электропередачи нет: инфраструктура заложена в основание города |
| **Износ** | Постепенная потеря пригодности предмета. Главный сток экономики |

## Экономика

| Термин | Значение |
|---|---|
| **Источник (faucet)** | Механика, вводящая ценность в мир. В OctoVerse по сути один — PoW-добыча |
| **Сток (sink)** | Механика, выводящая ценность из мира: износ, порча, расход, гибель, налог-сжигание |
| **Локальный рынок** | Книга заявок конкретного поселения. Глобального рынка нет |
| **Заявка** | Приказ купить/продать по цене. Bid — покупка, Ask — продажа |
| **Спред** | Разница между лучшей заявкой на покупку и на продажу. Показатель ликвидности |
| **Арбитраж** | Заработок на разнице цен между узлами. Основа профессии перевозчика |
| **Монета** | Золотая или серебряная монета, чеканится игроками. Физический предмет с весом. Средство межпланетных расчётов |
| **Монетный двор** | Постройка для чеканки монеты из драгметалла |
| **Проба** | Содержание драгметалла в монете. Может быть занижена эмитентом — порча монеты |
| **Планетарный кредит (₮, ₳)** | Электронные деньги, создаваемые банками. Ходят только в пределах одной планеты |
| **Банковский хаб** | Центральный узел денежной системы в столице Терры. Не может обанкротиться |
| **Терминал** | Банк в городе: постройка, дающая доступ к счёту. Деньгами не владеет |
| **Ключевая ставка** | Главный рычаг управления инфляцией. Вычисляется по публичной формуле |
| **Эскроу** | Удержание оплаты третьей стороной до исполнения сделки. Реализуется игроками, не движком |

## Общество

| Термин | Значение |
|---|---|
| **Город-государство** | Игровое объединение с территорией, казной, законами и аппаратом принуждения |
| **Устав** | Конституция города: форма правления, порядок изменения законов |
| **Кодекс** | Свод действующих законов города |
| **Код-закон** | Правило, исполняемое движком автоматически (налог, пропуск, комендантский час) |
| **Закон-переключатель** | Вопрос с конечным набором вариантов; доступные варианты зависят от ранее принятых законов |
| **Слово-закон** | Правило, записанное текстом; исполняется через жалобу, суд и санкции |
| **Столица Терры** | Первый город мира. Владеет Принтером Предтеч, полнейшей Библиотекой и банковским хабом |
| **Санкционный примитив** | Действие, которое движок умеет применить к игроку по решению власти: штраф, конфискация, запрет входа, мут в городском канале, метка |
| **Гражданство** | Формальная принадлежность игрока городу. Даёт права и обязанности, включая право на печать тела |
| **Метка «вне закона»** | Статус, лишающий защиты города; насилие против носителя законно |
| **Магистрат** | Обобщённое название носителя исполнительной власти (как бы его ни назвали игроки) |
| **Репутация** | Публичная история исполненных и нарушенных обязательств |

## Технические

| Термин | Значение |
|---|---|
| **Тик** | Дискретный шаг мировой симуляции |
| **Длительное действие** | Действие, продолжающееся, пока игрок офлайн |
| **Присутственное действие** | Действие, требующее живого игрока в момент выполнения |
| **Окно реакции** | Гарантированный срок, в течение которого игрок может ответить на угрозу до необратимых последствий |

## Терминологические запреты

Не используем в документации, чтобы не тащить чужие ожидания:

- «квест» → задача/контракт (между игроками)
- «моб», «монстр» → опасность/среда
- «гильдия» → город-государство / компания
- «уровень», «опыт», «навык», «прокачка» → знание, репутация, имущество
- «аукцион» → локальный рынок
- «фарм» → добыча / производство
