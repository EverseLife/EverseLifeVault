# Формы правления

> **Статус:** в реализации в части голосования граждан (D-036, D-161) — `engine/vote.py`: `law_approval: citizens` созывает голосование на `vote.duration`, ценз по `vote_qualification` (все · по сроку проживания · по имуществу), кворум и порог сняты при созыве, итог применяется заданием журнала. выборы правителя (`ruler_selection: elected_citizens`) и отзыв (`ruler_recall: by_citizens`) идут той же машиной, избранный получает набор прежнего правителя (D-162). срок полномочий (`ruler_term: fixed`) снимает должность заданием журнала, а сам устав правится по своей же процедуре `charter_amendment` — вплоть до `never` (D-163). совет собирается выборами либо назначением и утверждает законы своим кругом (`council_exists`, `law_approval: council`, `lawmaker: council`, D-164). правителя выбирает и отзывает тот круг, который назвал устав — город либо совет (D-165). Жребий, наследование, назначение преемника, места по вкладу в казну и тайное голосование ещё не сделаны; ценз по вкладу в казну не исполняется — учёта вклада нет
>
> **Числа** — стартовые значения из [реестра констант](../30-economy/07-constants.md); правятся на живой игре и в тексте не обсуждаются (D-065).

## Принцип: не список режимов, а конструктор

Соблазн — сделать меню: «выберите форму правления: монархия / республика / олигархия». Это плохо: игроки получат три пресета и упрутся в их границы.

**Правильно: набор параметров устава.** Форма правления — это конфигурация, а название ей игроки дадут сами.

## Законы-переключатели (D-036)

Закон формулируется как **вопрос с конечным набором вариантов**, причём доступные варианты **зависят от ранее выбранных законов**.

Например, закон «Как определяется лидер города?» предлагает три варианта: назначение по приказу действующего лидера; выборы жителями из состава парламента; открытое выдвижение, когда любой подаёт заявку с предвыборной программой. Второй вариант доступен, только если ранее принят закон о существовании парламента, — иначе его в списке просто нет.

Почему это правильная форма:

| | Свободный текст | Законы-переключатели |
|---|---|---|
| Что может движок | Ничего, только хранить | **Исполнять автоматически** |
| Свобода игрока | Полная, но без последствий | Ограниченная, но реальная |
| Работа разработчика | Ноль | Конечный, управляемый набор состояний |
| Понятность игроку | «Что это значит на практике?» | Каждый вариант описан своим механическим действием |

Ключевое достоинство: **разработчик заранее знает все состояния движка.** Комбинаций много, но каждая собрана из проверенных кусочков — не нужно ни интерпретировать текст, ни угадывать намерение.

### Зависимости как дерево

Устав перестаёт быть набором независимых галочек и становится **деревом решений**: выбор одного закона открывает или закрывает целые ветви других.

Первый закон — «Кто создаёт законы?». Ответ «только лидер» закрывает всю парламентскую ветвь: связанные с ней вопросы просто не появляются. Ответ «парламент» открывает сразу несколько новых: как парламент формируется, сколько в нём мест, как определяется лидер, каков порог принятия решений и может ли парламент сместить лидера.

Практические следствия:
- **Учредительный выбор необратим по духу.** Основатель, выбравший единоличную власть, закрыл себе ветвь республики — вернуться можно только через изменение самого устава, а это отдельная и трудная процедура
- **Государство читается с одного экрана.** Игрок видит дерево принятых законов и сразу понимает, во что ввязывается
- **Разработчик расширяет систему постепенно**, добавляя новые вопросы и ветви, не переписывая существующие города

### Слово-законы остаются

Переключатели покрывают устройство власти и всё, что движок умеет исполнять. Всё остальное — запрет брани, обязанность отработки, торговые ограничения — остаётся [слово-законами](02-law-engine.md) со связкой «жалоба → суд → санкция».

Две системы дополняют друг друга: переключатели задают **кто и как решает**, слово-законы — **что именно запрещено**.

### Территория тоже регулируется законами

Поскольку механик войны нет (D-020), переход узлов между городами описывается теми же переключателями: разрешена ли продажа территории, кто вправе её отчуждать, что происходит с постройками прежнего владельца, требуется ли согласие жителей узла.

## Параметры устава

| Раздел | Вопрос | Варианты |
|---|---|---|
| **Власть** | Кто занимает пост правителя | основатель · назначение · выборы · жребий · наследование |
| | Срок полномочий | бессрочно · N суток |
| | Возможен ли отзыв | невозможен · по решению совета · по голосованию граждан |
| **Законодательство** | Кто вносит законы | правитель · совет · любой гражданин |
| | Кто утверждает | правитель · совет большинством · все граждане |
| | Порог принятия | простое большинство · две трети · единогласие |
| | Кворум | доля граждан |
| **Казна** | Распорядители | правитель · совет · казначей |
| | Порог многоподписи | сумма, выше которой нужно несколько подписей |
| | Публичность | открыта · только совету · закрыта |
| **Правосудие** | Кто судит | правитель · назначенные судьи · жюри из граждан |
| | Обжалование | нет · у правителя · у собрания |
| | Кто исполняет приговор | стража · любой гражданин · наёмник |
| **Гражданство** | Приём | по приглашению · по заявке с одобрением · свободный |
| | Ценз для голоса | все · по сроку проживания · по имуществу · по вкладу в казну |
| | Изгнание | кто вправе и по какой процедуре |
| **Биопринтер** | Условия печати | бесплатно гражданам · за плату · в долг · не печатать |
| **Изменение устава** | Процедура | невозможно · правителем · две трети граждан · единогласно |

Из этих переключателей собирается что угодно: абсолютная монархия, купеческая олигархия с имущественным цензом, прямая демократия, выборная республика со сменяемостью, теократия нимф, военная диктатура на срок войны.

## Примеры конфигураций

**Основатель-самодержец** (по умолчанию при основании)
Правитель — основатель, бессрочно, отзыв невозможен, законы вносит и утверждает сам, казна закрыта, судит сам. Простая, работающая с первого дня схема. Годится, пока город — это 5 друзей.

**Купеческая республика**
Правитель избирается на 30 суток гражданами с имущественным цензом; законы вносит любой гражданин, утверждает совет 2/3; казна открыта; судят назначенные судьи; изменение устава — 2/3.

**Прямая демократия**
Всё решается голосованием всех граждан, кворум 30%, простое большинство. Работает в маленьком активном городе, парализуется в большом.

**Совет старейшин**
Ценз по сроку проживания, жребий среди старейших, единогласие для изменения устава. Медленно, устойчиво, консервативно.

## Голосование

Механика, которая обязана быть надёжной:

- Голосование — **длительное действие** с объявленным сроком (часы—сутки), чтобы участвовали не только те, кто онлайн в момент созыва
- Уведомление всем имеющим право голоса, в том числе вне игры
- Видимость: открытое или тайное — параметр устава
- Результат применяется автоматически, если это код-закон

**Защита от накрутки:** право голоса зависит от гражданства, а гражданство — от времени и вклада. Плюс правило «один персонаж на аккаунт» ([60-meta/01](../60-meta/01-anti-cheat.md)). Без этого любая демократия превращается в соревнование мультиаккаунтов, и весь политический слой игры обесценивается. **Это не мелочь, а условие существования всей задумки.**

## Смена власти

Три пути, и все должны работать:

1. **Легальный** — по процедуре устава (выборы, отзыв)
2. **Легальный радикальный** — изменение самого устава
3. **Нелегальный** — переворот, захват ратуши силой, раскол города

Третий требует поддержки от механик войны ([04-diplomacy-and-war](04-diplomacy-and-war.md)). **Раскол** — отдельный случай: часть граждан уходит и основывает свой город рядом. Это должно быть возможно и не слишком дорого — иначе недовольным некуда деваться, и они просто уходят из игры.

## Должности

Устав позволяет создавать посты и назначать на них игроков с конкретными правами:

| Пост | Права |
|---|---|
| Правитель | По уставу |
| Казначей | Распоряжение казной в пределах лимита |
| Судья | Ведение дел, вынесение приговоров |
| Страж | Применение санкций, досмотр, задержание |
| Смотритель | Управление постройками; **право менять описание, баннер и фон локаций** ([50-interface/06](../50-interface/06-location-authoring.md)) |
| Посол | Право заключать договоры от имени города |
| **Мудрец** | Ведение Библиотеки города: рубрикация, описания, порядок ([20-systems/03](../20-systems/03-crafting.md)), D-076 |
| **Энергетик** | Содержание городской электростанции, закупка топлива, распоряжение пулом ([20-systems/12](../20-systems/12-energy.md)), D-082 |

Должность — это **набор прав в движке**, а не титул в описании. Назначил казначея — он реально может тратить. Отсюда доверие, предательство, растраты и отставки.

**У Мудреца намеренно узкие права**: рубрикация, описания, порядок и полнота — но **не** право отказать во вкладе или изъять положенное. Ограничения хранилища из D-053 сильнее любой городской должности, и это принципиально: город нанимает библиотекаря, а не цензора.

Должностям платят из казны ([30-economy/04](../30-economy/04-taxes-and-treasury.md)) — иначе никто не будет патрулировать.

## Совет городов — единственный надгородской орган (D-087)

Города суверенны, и над ними нет власти. Одно исключение появляется тогда, когда на Терре наберётся `bank.council_handover_cities` городов с администрацией: **Совет городов принимает ключевую ставку** — цену денег для всей планеты ([30-economy/06](../30-economy/06-banking.md)).

| Правило | Как устроено |
|---|---|
| **Состав** | По одному представителю от каждого города с администрацией |
| **Голос** | Один город — один голос. Не по обороту, не по населению |
| **Полномочие** | Ровно одно: ставка в коридоре ±`bank.council_rate_deviation` от рекомендации алгоритма |
| **Периодичность** | Не чаще `bank.rate_review_period` |
| **Публичность** | Рекомендация, решение и поимённое голосование видны всем |
| **Аварийный автомат** | Инфляция вышла за `bank.inflation_alarm` — ставка возвращается алгоритму на `bank.council_lockout` суток |

**Почему полномочие ровно одно.** Совет — не второе правительство и не суд над городами. Он не отменяет местные законы, не собирает налоги и не распоряжается чужой казной. Единственная общая для всех величина — цена денег, и только она передаётся вверх. Всё остальное остаётся у городов, как и было.

Собственный бюджет у Совета появляется раньше полномочий: процентный доход банковской системы распределяется по казнам городов ещё до передачи ставки. Институт рождается с деньгами в руках, и первые споры в нём будут о том, чей оборот как считается.

## Должности и подписка

Отдельное правило, вытекающее из D-038: игрок, не оплативший подписку, **через 7 суток автоматически освобождает должность**. С государственной должности его могут снять и раньше — приказом.

Это необходимая страховка: без неё один пропавший казначей парализует город на неопределённый срок. Устав может задать свой, более короткий срок, но не может отменить правило.

## Открытые вопросы

- Закрыто (D-094): каталог устава живёт в [`data/laws.yaml`](../data/laws.yaml) и генерирует [07-law-catalog](07-law-catalog.md). Счёт вопросов и вариантов — в самом каталоге, он растёт вместе с данными
- Каталог законов-переключателей заведён в данных и растёт там же ([07-law-catalog](07-law-catalog.md), D-094). Это работа объёмом со список рецептов, и она продолжается
- Закрыто (D-094): преемник — отдельный вопрос устава `succession`, срабатывает после `charter.silence_days` суток молчания правителя
- Партии и фракции внутри города — нужны ли инструменты? Рекомендация: нет, игроки сделают сами через чаты и соглашения
