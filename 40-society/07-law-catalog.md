# Каталог законов

> **Статус:** генерируется · **Источник:** [`data/laws.yaml`](../data/laws.yaml) · **Решения:** D-004, D-036, D-094 · **Зависит от:** [01-government-forms](01-government-forms.md), [02-law-engine](02-law-engine.md)

> Этот файл собирается командой `python tools/build.py`. **Руками не править** — правки затрутся. Закон меняется в `data/laws.yaml`, оттуда он попадает и сюда, и в `build/laws.json`, который читает движок.

Полный перечень того, из чего игроки собирают своё государство.

## Три слоя, и они разные (D-094)

| Слой | Кто пишет | Кто исполняет | Гибкость |
|---|---|---|---|
| **Устав** — законы-переключатели | Мы, заранее. Игрок выбирает вариант | Движок, автоматически | Конечный набор состояний |
| **Код-законы территории** | Мы, заранее. Игрок задаёт значение | Движок, автоматически | Число или режим |
| **Слово-законы** | Игрок, свободным текстом | Люди: жалоба → суд → санкция | Полная |

**Почему именно так.** Переключатель движок умеет исполнить, но игрок ограничен списком. Текст игрок пишет какой угодно, но движок в нём ничего не понимает и исполнять не может. Ни один из двух подходов не покрывает задачу в одиночку, поэтому в игре есть оба — и граница между ними проходит ровно там, где кончается то, что движок способен проверить сам.

Устав отвечает на вопрос **кто и как решает**. Слово-законы — на вопрос **что именно запрещено**.

## Устав: законы-переключатели

Вопрос с конечным набором вариантов, причём доступные варианты зависят от ранее выбранных (D-036). Отметка *(требует …)* означает, что вопрос или вариант появляется только при определённом выборе выше.

**Жирным набран вариант по умолчанию** — состояние, в котором город возникает, пока основатель ничего не менял (D-130). Умолчания складываются в работающий город одного человека: власть у основателя, вход свободный, казна открыта, суд его же.

| Вопрос | Варианты |
|---|---|
| **Власть** | |
| Как определяется правитель<br>`ruler_selection` | **основатель бессрочно** · назначается предыдущим правителем · наследуется · выбирается гражданами · выбирается советом *(требует: council_exists)* · жребий среди граждан |
| Срок полномочий правителя<br>`ruler_term` | **бессрочно** · срок в сутках *(суток)* |
| Можно ли отозвать правителя досрочно<br>`ruler_recall` | **нельзя** · решением совета *(требует: council_exists)* · голосованием граждан |
| Кто принимает власть, если правитель молчит `charter.silence_days` суток<br>`succession` | заранее указанный преемник · совет *(требует: council_exists)* · **досрочные выборы** · старшая по уставу должность |
| Есть ли совет<br>`council_exists` | **совета нет** · избирается гражданами *(мест)* · назначается правителем *(мест)* · места по вкладу в казну *(мест)* |
| **Законодательство** | |
| Кто вносит законы<br>`lawmaker` | **только правитель** · совет *(требует: council_exists)* · любой гражданин |

| Порог принятия *(требует: law_approval = council / citizens)*<br>`law_threshold` | **простое большинство** · две трети · единогласно |
| Кворум голосования *(требует: law_approval = council / citizens)*<br>`quorum` | **не требуется** · доля имеющих право голоса *(%)* |
| **Казна** | |
| Кто распоряжается казной<br>`treasury_access` | **правитель** · совет *(требует: council_exists)* · назначенный казначей |

| Кому видна казна<br>`treasury_publicity` | **всем** · только совету *(требует: council_exists)* · только распорядителям |
| **Правосудие** | |
| Кто судит<br>`judge` | **правитель** · назначенные судьи · жюри из граждан *(человек)* |
| Можно ли обжаловать приговор<br>`appeal` | нельзя · **у правителя** · у собрания граждан |
| Кто исполняет приговор<br>`executor` | **городская стража** · любой гражданин · нанятый исполнитель |
| **Гражданство** | |
| Как принимают в граждане<br>`citizenship_admission` | **свободно** · по заявке с одобрением · только по приглашению |
| Ценз для права голоса<br>`vote_qualification` | **все граждане** · по сроку проживания *(суток)* · по имуществу *(ТК)* · по вкладу в казну *(ТК)* |
| Кто вправе изгнать из города<br>`exile` | **правитель** · только суд · голосование граждан |
| **Биопринтер** | |
| На каких условиях печатают тело<br>`print_terms` | бесплатно гражданам · **за плату по тарифу** · в долг перед городом · только гражданам |
| **Хозяйство** | |
| Регулирует ли город цену на еду<br>`food_policy` | **свободный рынок** · потолок цены на перечисленные товары *(ТК за единицу)* · потолок цены с нормой отпуска *(единиц в сутки)* |
| Куда город тратит излишек казны<br>`surplus_use` | **новые дороги и содержание существующих** · в резерв казны · выплаты гражданам · выкуп рецептов в Библиотеку |
| Кто устанавливает пошлины и запреты на ввоз и вывоз<br>`trade_authority` | **правитель единолично** · совет *(требует: council_exists)* · голосованием граждан · никто — граница всегда свободна |
| **Изменение устава** | |
| Как меняется сам устав<br>`charter_amendment` | не меняется · **правителем** · двумя третями граждан · единогласно |

**Учредительный выбор необратим по духу.** Основатель, выбравший единоличную власть, закрыл себе ветвь республики — вернуться можно только через изменение самого устава, а это отдельная и трудная процедура.

## Код-законы территории

Действуют на всех узлах города. У них не вариант, а **значение**: ставка, доля, режим доступа. Меняются по процедуре, которую задал устав.

Колонка «по умолчанию» — то, с чем город начинает жизнь (D-130). Молодой город стартует с **низким налогом с продажи, нулевыми пошлинами и открытой границей**: он должен привлекать, а не отпугивать, а поднять ставку основатель успеет всегда.

| Закон | Значение | По умолчанию | Смысл |
|---|---|---|---|
| **Налог с продажи**<br>`tax_trade` | % выручки | 3 | Платит продавец при исполнении ордера. Покупатель видит цену без налога — она и есть цена (D-127) |
| **Земельный налог**<br>`tax_land` | ТК/м² застройки в сутки у центра | 0.2 | Берётся с застроенной площади, а не с участка; двор не облагается. Ставка у биопринтера; с каждым узлом от него дешевеет на `land.decay_per_node` (D-220) (D-127) |
| **Цена городской земли**<br>`land_price` | ТК/м² у центра | 2 | Выкуп свободного участка любым жителем. Ставка у биопринтера; с каждым узлом от него дешевеет на `land.decay_per_node`. Выручка идёт в казну (D-089) |
| **Жалованье должностям**<br>`salary` | ТК в сутки | 0 | Суточный тик из казны. Не платится — должность слагается сама (D-127) |
| **Награда за поимку**<br>`bounty` | ТК | 0 | Из казны тому, кто исполнил приговор над меченым вне закона (D-127) |
| **Подъёмные новичку**<br>`newcomer_grant` | ТК | 0 | Из казны при первой печати тела в городе. Один раз на личность. Ноль — город не платит ничего (D-153) |
| **Гражданство при печати**<br>`spawn_citizenship` | — | нет | нет · обязательно. Выбравший эту дверь новичок становится гражданином в момент печати, минуя приём: согласие он дал выбором двери. Условие видно на карточке до выбора (D-184) |
| **Срок обязательства новичка**<br>`spawn_term` | суток | 0 | Сколько суток нельзя сложить гражданство, взятое при печати. Срок записывается в момент печати и позже не меняется. Ноль — уйти можно в тот же день. Без обязательного гражданства ни к чему не относится (D-184) |
| **Печать тела за счёт города**<br>`body_print` | — | нет | нет · гражданам · всем. Энергия всё равно списывается по тарифу — просто платит казна (D-032) |
| **Налог на добычу**<br>`tax_mining` | % выхода | 5 | Списывается с сессии добычи |
| **Налог на банковские операции**<br>`tax_bank` | % | 0 | С операций через терминал города |
| **Маржа городского банка**<br>`bank_margin` | % сверх ключевой | 2 | Надбавка города к ключевой ставке для своих заёмщиков. Потолок — `bank.city_margin_cap`; города конкурируют ставкой, как налогом и тарифом (D-175) |

| **Тариф на энергию**<br>`energy_tariff` | ТК/100 энергии | `energy.tariff_default` | Ноль означает бесплатную энергию (D-085) |
| **Доступ на территорию**<br>`access` | — | свободный | свободный · по гражданству · по разрешению · закрыт |

| **Пошлина на вывоз**<br>`export_duty` | % стоимости сверх нормы | 0 | То же для вывоза. Мягкая защита внутреннего производства (D-123) |
| **Запрет ввоза**<br>`import_ban` | — | пусто | Перечисленное движок не вносит на территорию города вовсе (D-123) |
| **Запрет вывоза**<br>`export_ban` | — | пусто | Перечисленное движок не выносит за пределы города. Жёсткая защита — руда остаётся своим цехам (D-123) |

## Санкционные примитивы

Всё, что движок умеет применить к игроку по решению власти или суда. Список закрытый: если санкции нет здесь — её не существует, и город может добиваться своего только договором, репутацией и общественным давлением (П5).

| Санкция | Что делает |
|---|---|
| **Штраф**<br>`fine` | Списание со счёта, при нехватке — долг перед городом |
| **Конфискация**<br>`confiscation` | Имущество на территории города |
| **Запрет входа**<br>`ban_entry` | На территорию города |
| **Мут в городском канале**<br>`mute` | Живое общение в локации не затрагивает |
| **Метка «вне закона»**<br>`outlaw` | Лишает защиты города (D-019) |
| **Заключение**<br>`prison` | Принудительное ограничение перемещения узлом на срок. Тот же примитив, что и при несостоятельности (D-095) |
| **Присуждение**<br>`award` | Спорное имущество или сумма передаются истцу. Без этого суд наказывает, но не восстанавливает (D-117) |
| **Предписание о сносе**<br>`demolition_order` | Городу разрешено разобрать постройку нарушителя своими силами (D-095) |
| **Изгнание**<br>`exile` | Лишение гражданства вместе с запретом входа. Изгнанный спокойно живёт в другом городе |
| **Лишение лицензии**<br>`license_revoke` | Не может заниматься лицензированным делом на территории города |
| **Лишение должности**<br>`office_removal` | Снятие полномочий вместе с жалованьем |
| **Арест имущества**<br>`asset_freeze` | Заморозка счёта и склада до решения суда. Обратима |
| **Запрет на сделки**<br>`trade_ban` | Не может выставлять и исполнять ордера на городском рынке |
| **Изъятие в счёт долга**<br>`debt_collection` | Принудительное исполнение обязательства. Необратимо, в отличие от ареста |

## Слово-законы

В каталог не входят по определению: их пишет сам город свободным текстом ([02-law-engine](02-law-engine.md)). Движок хранит текст и связывает с ним жалобы, но смысла не понимает.

Работают через связку **жалоба → суд → санкционный примитив**. Именно поэтому список примитивов выше и есть настоящая граница власти города: всё, что нельзя выразить через них, остаётся словами.
