# Профессии

> **Статус:** черновик v0.1

## Главный принцип

**В игре нет системы профессий.** Есть знания, оборудование и потребности. «Профессия» — это то, как игроки себя называют, обнаружив нишу.

Разница принципиальная: если сделать «класс: шахтёр» с меню профессии — игроки будут выбирать из списка. Если дать инструменты и дефициты — они изобретут роли, которых мы не придумали. Второе и есть цель.

Ниже — не список классов, а **прогноз**: какие роли неизбежно возникнут и что движок обязан для них уметь.

---

## Уровень 1: первичные (напрямую поддержаны механиками)

| Роль | Чем занимается | Что нужно от движка |
|---|---|---|
| **Шахтёр** | PoW-добыча руд | Механика забоя, инструменты, усталость |
| **Разведчик недр** | Ищет жилы, продаёт координаты | Разведка как действие; координаты как передаваемый объект |
| **Фермер** | Растит еду и волокно | Земля, участки, циклы роста, право собственности на землю |
| **Селекционер** | Выводит новые сорта и торгует семенами и агротехникой | Скрещивание, отбор, авторство сорта ([14-plants-and-breeding](14-plants-and-breeding.md)) |
| **Металлург / кузнец / столяр / ткач** | Переделы | Оборудование, чертежи, качество, клеймо |
| **Строитель** | Здания, дороги, укрепления | Проекты, вклад материалов и труда нескольких игроков |
| **Инженер** | Транспорт, двигатели, машины | Верхние переделы, пироксит |
| **Медик / фармацевт** | Лечение, снятие статусов | Травмы, статусы, лекарства как расходники |
| **Био-культиватор (нимфы)** | Выращивает материалы | Отдельная ветка производства |
| **Монетчик** | Чеканит монету из золота и серебра | Монетный двор, проба, клеймо (D-016) |
| **Смотритель биопринтера** | Обслуживает печать тел, ведёт учёт запасов | Биопринтер как постройка города (D-013) |

## Уровень 2: эмерджентные (возникают сами, если не мешать)

Эти роли **нельзя реализовать напрямую** — они появляются из разницы цен, риска и доверия. Наша задача — не «сделать профессию перевозчика», а обеспечить условия, при которых она выгодна.

| Роль | Откуда берётся | Условия существования |
|---|---|---|
| **Перевозчик / торговец** | Разница цен между узлами | Локальные рынки, ограничение переноски, транспорт, время в пути |
| **Караванщик** | Объёмы больше одного транспорта | Групповое движение, общий груз |
| **Охранник каравана** | Риск на маршруте | Наличие угрозы (D-019), контракт на сопровождение |
| **Пират / разбойник** | Ценный груз на дороге | Разрешённое насилие в определённых зонах, возможность отнять груз |
| **Скупщик** | Мелкие продавцы не хотят возить | Возможность выставлять заявки на покупку |
| **Спекулянт** | Информационная асимметрия | Задержка распространения информации о ценах |
| **Ростовщик** | Банк даёт кредит не всем: без залога и истории — отказ | Частные займы между игроками на своих условиях ([30-economy/03](../30-economy/03-contracts.md)) |
| **Меняла** | Две формы денег с плавающим курсом; терминал есть не везде | Обмен монета↔кредит, в том числе там, где терминала нет |
| **Углевоз** | Станция принадлежит городу, но топливо для неё добывают и возят игроки (D-082) | Контракты на поставку угля; остановка поставок останавливает город ([12-energy](12-energy.md)) |
| **Перекупщик заряда** | Вне города энергии нет вовсе — только аккумуляторы | Вес и саморазряд аккумулятора, разница тарифов между городами |
| **Развозчик рецептов** | Библиотека бесплатна, но она одна и она на Терре | Носители рецептов; цена равна сэкономленному пути (D-053) |
| **Изобретатель** | Выше Библиотеки рецептов нет, их надо додумывать | Механика изобретения; первый двигатель II класса — самое ценное знание в истории мира |
| **Инкассатор** | Монету надо физически возить, в том числе между планетами | Вес денег, риск на маршруте |
| **Фальшивомонетчик** | Проба монеты не видна без проверки | Возможность занизить содержание металла |
| **Страховщик грузов** | Экспедиции гибнут | Обязательство выплаты, подтверждаемое публично |
| **Страховщик жизни** | Печать тела стоит ресурсов (D-012) | Взнос заранее — покрытие печати при гибели. Буквально страхование жизни |
| **Агент на месте** | Цены известны только там, где есть свой человек (D-010) | Мгновенная связь + локальность рыночных данных |
| **Наёмник** | Есть спрос на частное насилие (D-019) | Наём, оплата, репутация |
| **Охотник за головами** | Города метят преступников | Метка «вне закона», награда из казны |
| **Разведчик рынка / информатор** | Цены неизвестны на расстоянии | Информация как передаваемый объект |
| **Юрист / судья** | Законы городов сложны | Работающий движок законов и суда |
| **Вербовщик** | Городам нужны люди | Новички у Принтера, выгода от их привлечения |
| **Наставник / патрон** | Новичок беспомощен | Механика ученичества с отдачей ([60-meta/00](../60-meta/00-onboarding.md)) |
| **Аукционист / посредник (эскроу)** | Сделки требуют доверия | Возможность передать вещь третьему лицу и публичная репутация |
| **Мошенник** | Есть доверие, значит есть, что обмануть | Мы это не запрещаем (столп П5) |

**Проверочный вопрос при добавлении любой фичи:** «какую из эмерджентных ролей это убивает?» Например, глобальный аукцион убивает сразу шесть строк таблицы.

## Что движок обязан уметь ради эмерджентности

Это фактически технический чеклист, вытекающий из таблицы выше:

1. **Передача чего угодно между игроками** — предметы, деньги, знания, координаты, права доступа
2. **Отложенные обязательства** — контракты с условиями и сроком ([30-economy/03](../30-economy/03-contracts.md))
3. **Права доступа** — на склад, мастерскую, транспорт, постройку, счёт
4. **Доли** — совместное владение и автоматическое разделение дохода
5. **Публичная история** — репутация, видимая всем
6. **Наём** — предложение работы, оплата за результат или за время
7. **Объявления** — доска, где можно искать людей и работу

Без пунктов 1–7 никакая эмерджентная профессия не появится, сколько ни пиши в описании игры «свободная экономика».

## Специализация и запрет на универсала

Если один игрок может добывать, плавить, ковать, возить и продавать — он не нуждается в других, и социальная игра исчезает.

Барьеры против универсальности:
- **Время** — сутки конечны, выносливость ограничена
- **Знание** — пропорции, агротехника и рецепты не выучиваются все сразу ([15-quality](15-quality.md))
- **Оборудование** — дорого содержать всё сразу
- **География** — руда в горах, поле в долине, порт на берегу. Нельзя быть везде
- **Переноска** — не увезёшь всё сам

Из них **география и переноска** — самые сильные и самые дешёвые в реализации.
