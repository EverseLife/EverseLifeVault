# Уведомления и асинхронность

> **Статус:** идея

В асинхронной игре уведомления — не удобство, а несущая механика. Именно они позволяют игроку не сидеть в клиенте и при этом не терять всё.

## Что игрок обязан узнать, даже будучи офлайн

| Событие                                          | Срочность    | Канал                  |
| ------------------------------------------------ | ------------ | ---------------------- |
| Твоё имущество под угрозой (осада, взлом, арест) | Критично     | Пуш + почта            |
| Против тебя возбуждено дело                      | Высокая      | Пуш + почта            |
| Голосование, где у тебя есть голос               | Средняя      | Почта, пуш опционально |
| Караван прибыл / остановлен                      | Средняя      | Пуш опционально        |
| Контракт истекает через N часов                  | Средняя      | Пуш опционально        |
| Заявка исполнена                                 | Низкая       | Лента                  |
| Партия готова, урожай созрел                     | Низкая       | Лента                  |
| Изменение законов города, где ты гражданин       | Средняя      | Почта                  |
| Тебе написали лично                              | По настройке | Пуш                    |

**Правило:** любое событие с необратимыми последствиями обязано иметь уведомление **и** окно реакции ([20-systems/01](../20-systems/01-time-model.md)). Одно без другого бессмысленно.

**Строка про голосование — уже не замысел (2026-09-02).** Опрос своего города
приходит во вкладку «Сеть»: счётчиком на самой вкладке, строкой с предметом,
городом, счётом и сроком — и отвечается прямо там, где прочитан. Так и должно
быть по [D-161](../90-production/02-decision-log.md): голос подаётся по Сети,
присутствие нужно, чтобы **править**, а не чтобы участвовать; до этого
голосование рисовалось только в администрации, то есть доходило ровно до тех,
кому уведомление и не требовалось. Тот же опрос стоит в списке внимания сводки
возвращения. Пуша нет — его нет пока ни у чего.

## Каналы доставки

- **В игре** — лента и значки
- **Пуш** (PWA / мобильное приложение) — критичное
- **Почта в игре** — всё, что не срочно, ждёт возвращения
- **Внешние** (e-mail, Telegram-бот) — опционально, по желанию игрока

Telegram-бот стоит рассмотреть всерьёз: для текстовой асинхронной игры это естественная вторая точка входа. Даже read-only бот («твой караван прибыл», «в городе голосование») сильно повышает удержание.

**Осторожно:** двусторонний бот, позволяющий совершать действия, — это ещё одна поверхность для ботоводства. Рекомендация: только чтение и подтверждение простых решений (голос, продление).

## Сводка при возвращении

Самый важный экран асинхронной игры. Игрок заходит после суток отсутствия и должен за 10 секунд понять, что произошло.

Экран открывается сразу при входе и разбит на три уровня.

**Требует внимания** — то, где ещё можно успеть что-то сделать: судебное дело с оставшимся сроком, истекающий контракт, идущее голосование, угроза имуществу. У каждой строки виден остаток времени в реальных часах.

**Произошло** — свершившееся и уже не требующее реакции: караван дошёл и продал груз, партия готова, урожай собран, город изменил налог.

**Разговоры** — свёрнутый счётчик сообщений, разворачиваемый по желанию.

Первый блок никогда не длиннее пяти строк. Если он разрастается, значит важность размечена неправильно.

## Против уведомительного шума

Худший исход — игрок отключает уведомления, потом пропускает осаду и уходит из игры.

Меры:
- Тонкая настройка по типам событий
- Умное объединение («7 сделок исполнено», а не семь пушей)
- Ночной режим по часовому поясу игрока — **кроме критичных**
- Критичные уведомления редки по определению: если игрок получает «критично» каждый день, значит мы неправильно разметили важность

## Тайминг враждебных действий

Отдельная проблема: атака в 4 утра по времени жертвы.

Смягчения (обсуждаемо):
- Осада всегда длится дольше типичного сна (12+ часов) → просыпаешься и успеваешь
- Город может законом установить «часы покоя», в которые осада идёт медленнее (интересно: у каждого города свой ритм, и это становится разведданными)
- Уведомление приходит немедленно всем гражданам

**Не делать:** полную неуязвимость по расписанию. Это ломает мир и порождает эксплойты.
